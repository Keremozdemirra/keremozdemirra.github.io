# keremozdemir.de

The site as it is served: [keremozdemir.de](https://keremozdemir.de).

This repository holds **generated output**, not source. A Next.js project is
exported to static files and the result is copied here whole, so editing a file
in this repository changes nothing that survives the next deploy. The source
lives in a separate repository.

Everything here is what a browser receives. The instruments, the games and the
simulations run in the page with no backend behind them, and nothing on the
site calls a third party after the fonts, which are served from this repository
too.

`/run/` holds the previous edition of the site, 61 pages of it, still working
and still addressable. Every URL that edition published redirects to its place
here rather than dying.
