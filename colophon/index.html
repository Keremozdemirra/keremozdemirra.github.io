How it is made.

Everything on this page can be checked against the repository.

Type

Fraunces for display, Instrument Sans for text, IBM Plex Mono for figures and labels, Newsreader in the notes. All four under the SIL Open Font License, served from this domain.

Stack

Next.js as a static export. No server, no database, no build-time secret. The pages are files.

Hosting

GitHub Pages, from a public repository. A push is a deploy.

What it does not do

No analytics, no trackers, no third-party request after the page has loaded. The language you choose is remembered in your own browser and nowhere else.

Licences

Third-party notices. The instruments and tools are open source; each repository names its licence.
